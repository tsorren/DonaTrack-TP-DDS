# Prompt — Tests Predefinidos

## Cuándo usar este prompt

Usá este prompt cuando ya tengas definidos los escenarios de prueba y necesites ayuda para escribir, completar o corregir tests concretos.

Sirve para:
- crear tests unitarios a partir de casos ya definidos;
- completar tests faltantes;
- corregir tests que fallan;
- mejorar nombres de tests;
- ordenar datos de prueba;
- agregar asserts relevantes;
- evitar tests frágiles o sin valor.

Este prompt no sirve para rediseñar toda la estrategia de testing. Para eso usar `media-diseno-testing.md`.

La prioridad es validar comportamiento, no solo aumentar cobertura.
