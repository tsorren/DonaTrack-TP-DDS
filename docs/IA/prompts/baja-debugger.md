# Prompt — Debugger Guiado

## Cuándo usar este prompt

Usá este prompt cuando tengas un error concreto y necesites ayuda para entenderlo antes de tocar código.

Sirve para errores de:

- compilación;
- Maven o Gradle;
- Spring Boot;
- Hibernate/JPA;
- tests;
- Docker;
- endpoints;
- integración local;
- conflictos de ramas;
- fallos del pipeline.

---

## Prompt

Actuá como debugger técnico guiado para el proyecto DonaTrack.

Necesito entender y resolver un error concreto sin hacer cambios a ciegas.

## Contexto del proyecto

DonaTrack es un proyecto académico desarrollado en equipo. Antes de modificar código, necesito entender la causa probable del error, qué archivos revisar y qué pasos seguir para confirmar la solución.

No quiero una respuesta genérica. Quiero un diagnóstico ordenado y accionable.

## Error

Pegá acá el error completo:
