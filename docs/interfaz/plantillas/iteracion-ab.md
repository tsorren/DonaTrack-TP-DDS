# Iteración A/B: <tema>

> Plantilla de la skill `iteracion-ab`. Una iteración = un tema del [catálogo](../temas-ab.md).
> El agente la completa en su trabajo. Al usuario solo le llega la sección 4.

## 1. Antes de construir

- **Tema:** `<tema>` · **Modo:** exploración o ajuste · **Vuelta:** 1 de 3
- **Qué se quiere decidir:** una frase.
- **Qué queda fijo:** lo que no cambia entre A y B.
- **Cómo se va a juzgar:** de 2 a 4 criterios, tomados del catálogo y del brief.

## 2. Variantes

| | A | B |
|---|---|---|
| Idea | | |
| Eje de divergencia (exploración): qué domina, claro u oscuro, temperatura, saturación o estructura | | |
| Qué la distingue | | |
| Riesgo | | |

En paleta, cambiar solo el tono de cada color en su mismo rol no cuenta como eje. En exploración,
desde la segunda vuelta, al menos una opción sale de la familia elegida en la anterior. Si dos
opciones se ven parecidas lado a lado, se rehace una antes de mostrarlas.

Si hay boceto de E1, una de las dos puede ser la versión fiel (sirve de control). No es
obligatorio.

## 3. Comprobación y autocrítica (no se le muestra al usuario)

- [ ] Exploración, en cada vuelta: capturas de boceto a 1280 px con página de comparación; las
  opciones se distinguen a simple vista y ninguna es tímida frente al brief.
- [ ] Ajuste, y la elegida de una exploración antes de aplicarla: pasa el piso (AA, toque de 48 px
  y nada desbordado entre 360 y 1920 px), con capturas en 360, 1280 y 1920 px.

| Criterio | A | B |
|---|---|---|
| | | |

Recomendación del agente y por qué.

## 4. Lo que ve el usuario

Imagen comparativa y, debajo:

- **A — <nombre corto>:** 2 o 3 líneas en palabras simples.
- **B — <nombre corto>:** 2 o 3 líneas en palabras simples.

Pregunta: "¿Con cuál seguimos?", con las opciones A (Recomendada), B, "Una mezcla" y "Ninguna,
probemos otra cosa".

## 5. Cierre

- Elección y motivo → entrada en la [bitácora](../bitacora.md), con el formato corto de las
  decisiones A/B (15 líneas o menos, una línea por vuelta).
- Capturas de la decisión → `docs/interfaz/evidencia/<tema>/`: 1280 px de las opciones de cada
  vuelta, y 360 y 1280 px de la elegida. Entre vueltas no se escribe evidencia ni bitácora.
- La variante descartada se borra del código.
