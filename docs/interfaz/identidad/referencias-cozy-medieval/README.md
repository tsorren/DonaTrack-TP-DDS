# Referencias visuales de Cozy / Medieval

> UTN-FRBA — Diseño de Sistemas (2026) — Grupo 5
> **2026-10-31 · las trajo el usuario · parte del [brief de Cozy / Medieval](../brief-cozy-medieval.md)**

El usuario las trajo para el rediseño de Cozy, con esta dirección (en sus palabras):

> Inspiración: esquemorfismo rústico. Evitar que sea gimmick-y. Buscar profesionalismo.
> Gamificación ligera, creatividad e identidad propia. Explorar, aventura.

Son **imágenes de terceros**, solo para inspirar: se toma el estilo, no se copia nada. No entran al
sitio ni al entregable de la cátedra. Las del 10 y el 11 ya estaban, como fotos, entre las seis
referencias del brief (el mapa a la luz de la vela y la carreta); la del 9 también.
