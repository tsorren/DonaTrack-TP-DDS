# Referencias visuales de Raíces

> UTN-FRBA — Diseño de Sistemas (2026) — Grupo 5
> **2026-10-31 · las trajo el usuario · tercera alternativa de identidad, en relevamiento**

El usuario las trajo para una alternativa nueva, con esta dirección (en sus palabras):

> Una alternativa nueva de identidad visual y diseño gráfico y UX/UI. Va a estar orientada al
> concepto de raíces y semillas, combinado con la logística, con el foco principal en las empresas
> que donan y quieren transparencia.

Son **imágenes de terceros**, solo para inspirar: se toma el estilo, no se copia nada. No entran al
sitio ni al entregable de la cátedra. La 07 y la 08 son capturas de un artifact de exploración de
direcciones de DonaTrack que trajo el usuario (versión "Calma").
