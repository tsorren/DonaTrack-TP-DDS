# Referencias visuales de Encastre

> UTN-FRBA — Diseño de Sistemas (2026) — Grupo 5
> **2026-10-31 · las trajo el usuario · parte del [brief de Encastre](../brief-encastre.md)**

El usuario las trajo para la tercera alternativa de identidad, con este pedido (en sus palabras):

> Inspiración de Opción 2: Encastre

Vienen de dos lugares:

- **La opción 2 de "Direcciones finales DonaTrack"** (un artifact de claude.ai con seis
  direcciones para el sitio): la portada y el tablero de Encastre. Son la **guía principal**.
- **El grupo "MODERNO" del tablero de inspiración en FigJam** (`inspo`): tableros y apps en pastel
  que empujan a Encastre más lejos. Se recortaron de capturas del tablero.

Son **imágenes de terceros**, solo para inspirar: se toma el estilo, no se copia nada. No entran al
sitio ni al entregable de la cátedra. Las 01 y 02 son demostraciones con datos inventados.

plantilla genérica de dashboard, todo pastel sin que nada se destaque, e ilustraciones de banco de
imágenes.
