# Encargos creativos

> UTN-FRBA — Diseño de Sistemas (2026) — Grupo 5
> **2026-10-31 · parte del [proceso de diseño](../README.md)**

Cada archivo de esta carpeta es un **encargo creativo aprobado por el usuario**: lo que pidió para
un diseño nuevo desde cero (sus palabras, las referencias, el mensaje, las libertades y los límites,
y hasta dónde llega la corrida). Lo arma la skill `relevamiento-creativo` con la
[plantilla](../plantillas/encargo-creativo.md) y lo lee la skill `corrida-creativa`, que trabaja
sin el usuario a partir de él.

Un encargo es un registro: no se edita después de aprobado. Si el usuario cambia de idea, se arma
uno nuevo y la bitácora dice cuál reemplaza.
